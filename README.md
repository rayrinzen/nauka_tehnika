# Інформаційний новинний веб-сайт «Наука та техніка»

Курсова робота з дисципліни «Веб-технології та веб-дизайн» на тему:  
**«Створення інформаційного новинного веб-сайту "Наука та техніка"»**.

Проєкт реалізовано як повнофункціональний веб-додаток на базі фреймворку **Laravel** із підключенням реляційної СУБД **MySQL**.

---

## Стек технологій
- **Backend:** PHP 8.0+, Laravel 9 (MVC, Eloquent ORM, Blade-шаблонізатор, Middleware-автентифікація)
- **Database:** MySQL 8.0
- **Frontend:** HTML5, CSS3 (з підтримкою темної/світлої теми), JavaScript
