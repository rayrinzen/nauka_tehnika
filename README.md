# Інформаційний новинний вебсайт «Наука та техніка»

## Опис проєкту

«Наука та техніка» — це інформаційний новинний вебсайт, призначений для публікації, зберігання, пошуку та перегляду новин у галузі науки, техніки, космосу та інформаційних технологій.

Проєкт розроблено з використанням PHP та фреймворку Laravel 9. Для зберігання інформації використовується реляційна система керування базами даних MySQL.

## Використані технології

- PHP 8.0.2 або новіша сумісна версія
- Laravel 9
- MySQL
- HTML5
- CSS3
- JavaScript
- Blade
- Eloquent ORM
- Composer
- Vite

## Функціональні можливості

- Перегляд списку новин.
- Пошук новин за ключовими словами.
- Фільтрація новин за категоріями.
- Перегляд повного тексту окремої новини.
- Підрахунок кількості переглядів.
- Авторизація адміністратора.
- Додавання нових новин.
- Видалення новин.
- Перемикання між світлою та темною темами оформлення.

## Вимоги для запуску

Для локального запуску проєкту необхідно встановити:

- PHP 8.0.2 або новішої сумісної версії;
- Composer;
- MySQL Server;
- Git;
- Node.js та npm (для роботи з frontend-залежностями).

## Інструкція з встановлення та запуску

### 1. Клонування репозиторію

Відкрийте термінал та виконайте:

```bash
git clone https://github.com/rayrinzen/nauka_tehnika.git
```

Перейдіть до каталогу проєкту:

```bash
cd nauka_tehnika
```

Laravel-застосунок розміщений безпосередньо в корені репозиторію.

### 2. Встановлення залежностей

Встановіть PHP-залежності:

```bash
composer install
```

### 3. Налаштування середовища

Створіть файл `.env` на основі `.env.example`.

Для Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Для Linux, macOS або Git Bash:

```bash
cp .env.example .env
```

Згенеруйте ключ застосунку:

```bash
php artisan key:generate
```

### 4. Налаштування бази даних MySQL

Створіть базу даних MySQL, наприклад `science_news`.

Відкрийте файл `.env` та налаштуйте параметри підключення:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=science_news
DB_USERNAME=root
DB_PASSWORD=
```

За необхідності змініть ім'я користувача та пароль відповідно до налаштувань вашого MySQL Server.

### 5. Створення таблиць бази даних

Виконайте міграції та заповнення бази початковими даними:

```bash
php artisan migrate --seed
```

### 6. Встановлення frontend-залежностей

За потреби встановіть залежності Node.js:

```bash
npm install
```

Для збирання frontend-ресурсів виконайте:

```bash
npm run build
```

### 7. Запуск вебсайту

Запустіть локальний сервер Laravel:

```bash
php artisan serve
```

Відкрийте браузер та перейдіть за адресою:

http://127.0.0.1:8000

Після виконання зазначених дій вебсайт буде доступний для локального використання.

## Структура проєкту

```text
nauka_tehnika/
├── app/              # Основна логіка застосунку
├── bootstrap/        # Ініціалізація Laravel
├── config/           # Конфігураційні файли
├── database/         # Міграції та початкові дані
├── lang/             # Мовні файли
├── public/           # Публічні файли
├── resources/        # Blade-шаблони, CSS та JavaScript
├── routes/           # Маршрути вебзастосунку
├── storage/          # Службові файли та журнали
├── tests/            # Автоматизовані тести
├── .env.example      # Приклад конфігурації
├── artisan           # Консольна команда Laravel
├── composer.json     # PHP-залежності
├── composer.lock     # Зафіксовані версії залежностей
├── package.json      # Frontend-залежності
├── phpunit.xml       # Налаштування тестування
└── vite.config.js    # Налаштування Vite
```

## База даних

Для зберігання інформації використовується MySQL.

Взаємодія серверної частини з базою даних здійснюється за допомогою Eloquent ORM.

Структура бази даних створюється за допомогою міграцій Laravel. Початкове наповнення виконується через механізм DatabaseSeeder.

## Безпека

- Адміністративна частина доступна після авторизації.
- Для захисту адміністративних маршрутів використовується middleware `auth`.
- Паролі користувачів зберігаються у вигляді хешів.
- Налаштування середовища зберігаються у файлі `.env`.

Файл `.env` не повинен публікуватися у відкритому репозиторії.
