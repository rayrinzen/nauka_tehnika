Інформаційний новинний вебсайт «Наука та техніка»
Курсова робота з дисципліни «Веб-технології та веб-дизайн» на тему «Створення інформаційного новинного вебсайту "Наука та техніка"».

Проєкт реалізовано як вебзастосунок на базі Laravel 9 із використанням PHP та реляційної системи керування базами даних MySQL.
1. Технології
- Backend: PHP ^8.0.2, Laravel ^9.19
- База даних: MySQL
- Frontend: Blade, HTML, CSS, JavaScript
- Робота з даними: Eloquent ORM
- Залежності PHP: Composer
- Frontend-залежності та збірка ресурсів: npm / Vite (за потреби)
2. Можливості вебсайту
- перегляд списку новин;
- пошук новин за текстом;
- фільтрація новин за категоріями;
- перегляд повної сторінки новини;
- підрахунок переглядів публікацій;
- вхід адміністратора;
- додавання та видалення новин через адміністративну панель;
- перемикання світлої та темної теми оформлення.
3. Вимоги для запуску
Перед початком роботи встановіть:
- PHP версії 8.0.2 або новішої, сумісної з Laravel 9;
- Composer;
- MySQL Server;
- Git.
Для збирання frontend-ресурсів також потрібні Node.js та npm.
4. Отримання проєкту
Клонуйте репозиторій та перейдіть до його каталогу:
git clone https://github.com/rayrinzen/nauka_tehnika.git
cd nauka_tehnika
У репозиторії Laravel-застосунок розміщений у корені. Додатково переходити до підкаталогу science-news-laravel після клонування не потрібно.

5. Встановлення залежностей
Встановіть PHP-залежності:
composer install
Створіть локальний файл налаштувань .env на основі прикладу:

Linux / macOS / Git Bash:
cp .env.example .env
Windows PowerShell:
Copy-Item .env.example .env
Згенеруйте ключ застосунку:
php artisan key:generate
6. Налаштування MySQL
1. Запустіть MySQL Server.
2. Створіть порожню базу даних, наприклад science_news.
3. Відкрийте файл .env та вкажіть параметри підключення до своєї бази даних:
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=science_news
DB_USERNAME=root
DB_PASSWORD=
За потреби замініть DB_USERNAME та DB_PASSWORD на власні облікові дані MySQL. Не публікуйте файл .env та реальні паролі у відкритому репозиторії.
7. Створення таблиць і початкових даних
Виконайте міграції та заповніть базу початковими даними:
php artisan migrate --seed
Команда запускає міграції та DatabaseSeeder. У поточному коді DatabaseSeeder створює демонстраційний обліковий запис адміністратора та початкові новини.

Демонстраційні дані для входу адміністратора:
- Email: admin@gmail.com
- Пароль: admin123
Ці облікові дані призначені лише для локальної демонстрації навчального проєкту. Для реального розгортання необхідно змінити пароль і не використовувати демонстраційний обліковий запис.
8. Збірка frontend-ресурсів
Якщо потрібно зібрати CSS та JavaScript за допомогою Vite, виконайте:
npm install
npm run build
Цей крок потребує встановлених Node.js та npm.
9. Запуск застосунку
Запустіть локальний сервер Laravel:
php artisan serve
Відкрийте у браузері:
http://127.0.0.1:8000
Для зупинки сервера натисніть Ctrl + C у терміналі.
10. Основні маршрути
Адреса	Призначення
/	Головна сторінка зі списком новин
/news/{news}	Перегляд окремої новини
/login	Форма входу адміністратора
/admin/news	Адміністративна панель після авторизації


Адміністративні маршрути захищені middleware auth.
11. Структура проєкту
nauka_tehnika/
├── app/                  # Контролери, моделі та логіка застосунку
├── bootstrap/            # Ініціалізація Laravel
├── config/               # Конфігураційні файли
├── database/
│   ├── migrations/       # Міграції бази даних
│   ├── seeders/          # Початкове наповнення бази даних
│   └── factories/        # Фабрики моделей
├── public/               # Публічна точка входу та ресурси
├── resources/
│   ├── views/            # Blade-шаблони
│   ├── css/              # CSS-ресурси
│   └── js/               # JavaScript-ресурси
├── routes/
│   └── web.php           # Маршрути вебзастосунку
├── storage/              # Логи та службові файли
├── tests/                # Автоматизовані тести
├── .env.example          # Приклад налаштувань середовища
├── artisan               # CLI Laravel
├── composer.json         # PHP-залежності
├── package.json          # Frontend-залежності
└── vite.config.js        # Налаштування Vite
12. Примітки
- Файл .env містить локальні налаштування та не повинен потрапляти до Git.
- Каталог vendor створюється командою composer install і не потрібно додавати до репозиторію.
- Каталог node_modules створюється командою npm install і не потрібно додавати до репозиторію.
- Якщо виникають проблеми з кешованими налаштуваннями, можна виконати:
php artisan optimize:clear
